# VELA website

Marketing site and waitlist for VELA. Next.js 16 (App Router), Tailwind CSS v4 and Framer Motion.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

`src/app/api/waitlist/route.ts` stores sign-ups in a local `waitlist.json` file, which works only in local development. See the [main README](../README.md) for the whole project.
